# Breeze Quest – Tourism Guide Agency UI Design

## 🌍 Project Overview

**Breeze Quest** is a modern, user-friendly tourism guide agency website design created using Figma. This project focuses on providing a clean and intuitive interface for users to explore travel destinations, book tours, and read client testimonials. It showcases the essential sections of a travel website, including a landing page, destination highlights, service offerings, and customer feedback.

## 🎨 Tools Used

- **Figma** – UI/UX design tool for wireframing and visual design
- **Typography & Colors** – Carefully selected for a professional and welcoming travel experience
- **Layout Design** – Responsive and scalable layouts ideal for future development

## 📁 Project Sections

- **Landing Page** – Introduces the agency with a call-to-action
- **Top Destinations** – Highlights locations like the Maldives, Canada, and the Netherlands
- **Our Services** – Lists what the agency offers (guided tours, custom itineraries, etc.)
- **Testimonials** – Client feedback showing how Breeze Quest supported their travel experience
- **Contact Section** – Encourages users to get in touch or plan their next trip

## ✨ Key Features

- Travel-focused and visually appealing UI
- Easy-to-navigate layout with clear user flow
- Designed with potential development and responsiveness in mind
- Realistic client testimonials to build trust

## 🙌 About the Designer

This project was created as part of my UI/UX learning journey. I focused on building a tourism-based design that is both aesthetic and functional. It's designed to be the base for a real-world travel booking website in the future.
